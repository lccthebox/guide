한국어 튜터 라운지
모바일 사용법

한국어 티칭 일정과 대타, 담당 원어민의 학습 진도를 함께 관리합니다.

한국어 튜터 라운지 접속하기
수업 일정대타 지원학습 진도

이 순서대로 사용하세요

1

정규 수업 결석 요청

수업 일정 → 정규 참석일 선택

  1. 결석 알리기 영역을 엽니다.
  2. 결석 사유와 전달사항을 반드시 작성합니다.
  3. 결석·대타 요청을 눌러 대타 모집을 시작합니다.
2

대타 가능한 날 등록

수업 일정 → 날짜 선택 → 대타 지원

  1. 가능한 날짜를 달력에서 선택합니다.
  2. 오전·오후 또는 주말 시간대를 고릅니다.
  3. 이날 대타 가능을 눌러 등록합니다.
3

열린 대타 요청 맡기

대타 → 대타 센터

  1. 열린 요청의 날짜·시간·담당자를 확인합니다.
  2. 가능한 요청에 지원합니다.
  3. 매칭 후 내 수업 일정에서 확정 상태를 확인합니다.
4

수업 진도 기록

학습 진도 → 담당 원어민 선택

  1. 수업 후 진행한 커리큘럼을 선택합니다.
  2. 진도·숙제·다음 수업 방향을 기록합니다.
  3. 저장 후 담당 원어민과 운영팀에 같은 내용이 보이는지 확인합니다.
수업 시작 시간: 한국어 수업은 정규 회화스터디보다 1시간 빠릅니다. 평일 오전 10시, 평일 저녁 7시, 주말 정오입니다.
결석 시 사유 입력은 필수이며, 대타가 확정되기 전에도 결석 요청 자체는 운영팀에 전달됩니다.
